# グラレコ風アイキャッチ画像を作る

ブログ「つみたて読書」の書評記事（`articles/book-review/<slug>.md`）に使うアイキャッチを作る。サイトの記事ページは 1600×900（16:9）で表示するので、その大きさで書き出す。

## 完成イメージ（構成は固定）

- **左**：本の表紙（少し傾けて、マスキングテープで貼ったように）
- **右**：白いパネルに、ラベル（例：あらすじ・名言・感想）→ **書名（大きく・黄色のマーカー線）** → 著者名 → 吹き出しのキャッチ
- **背景**：作品に合ったグラレコ風イラスト（太い茶色の線・ベタ塗り・小さな落書き）
- **右下**：「つみたて読書」のロゴ

見本：`articles/book-review/images/murakami-haruki-norwegian-wood/eyecatch.png`

## 手順

### 1. 記事を読む
`articles/book-review/<slug>.md` の title・excerpt・あらすじ（内容）・キーワード・時代背景を読み、**作品を象徴するモチーフを4〜6個**選ぶ（場所・季節・天気・小道具・時代の物）。
- 例（ノルウェイの森）：雨の草原、森（針葉樹）、野井戸、レコードと音符、赤と緑の葉（上下巻の色）
- ネタバレになるもの（結末・人物の生死・正体）は描かない
- 実在の人物の顔、他社のキャラクター・ロゴは描かない

### 2. 表紙の画像を用意する
- 置き場所：`articles/book-review/images/<slug>/cover.jpg`（png も可。縦長の表紙画像）
- この環境からは Amazon・出版社の画像を取りに行けない（ネットワークで遮断）。**表紙はユーザーにスクリーンショットを撮って置いてもらう**。最後の報告で、置き場所をはっきり伝える
- 表紙がないときは、パレットの2色で塗った「仮の本」を描く（書名と著者名入り）。仮の本のまま公開しないよう、報告で伝える
- 書影は、書評での紹介に使う範囲にとどめる（切り抜き・改変・装飾の上書きはしない。表紙全体をそのまま貼る）

### 3. 背景の SVG を描く（`images/<slug>/eyecatch-bg.svg`）
`viewBox="0 0 1600 900"`。グラレコ風のルール：
- **線**：色 `#3b2f2a`（こげ茶）、太さ4〜6、`stroke-linecap="round"`、`stroke-linejoin="round"`
- **塗り**：ベタ塗り（グラデーションなし）。パレットの色＋淡い色（空 `#dfe9e4`、雲 `#fffaf0` など）
- **落書き**：星・矢印・音符・風の線・雨粒など、小さな記号を2〜4個
- 描画のゆらぎ（手描きっぽさ）は、書き出しのときに自動でかかる。線はまっすぐ描いてよい
- **描いてよい場所**（パネルと表紙に隠れない場所）：
  - 上の帯：y < 190（全幅）
  - 下の帯：y > 700（全幅。地面・草原・道など）
  - 右の端：x > 1460
  - 表紙とパネルのすき間：x 560〜610
- **隠れる場所**（大事なものを置かない）：表紙 x 90〜580・y 100〜790、パネル x 610〜1450・y 205〜690
- 全体の空・地面の色は、上と下に大きく塗る。パネルの後ろも色が透けるので、空と地面の境目はパネルの下あたり（y 580〜650）に置くと落ち着く

### 4. 設定ファイルを書く（`images/<slug>/eyecatch.json`）
```json
{
  "title": "ノルウェイの森",
  "author": "村上春樹",
  "catch": "37歳の「僕」がふり返る、喪失と再生の物語",
  "label": "あらすじ・名言・感想",
  "background": "eyecatch-bg.svg",
  "cover": "cover.jpg",
  "palette": { "paper": "#f6efe0", "ink": "#3b2f2a", "accent": "#c8553d", "accent2": "#3f7d58", "marker": "#f5d76e" }
}
```
- `title`：『』なしの書名。副題は入れない。8字を超えるときは `"titleLines": ["前半", "後半"]` で2行に分ける（意味の切れ目で）
- `author`：著者名のみ（訳者は入れない）
- `catch`：記事の切り口を30字以内で。あおり言葉（神本・必読など）は使わない
- `label`：小説は「あらすじ・名言・感想」、非小説は「要約・感想」など
- `palette`：`accent`・`accent2` は作品のイメージ色（表紙の色や舞台の色）。`marker` は書名の下のマーカー色

### 5. 書き出す
```bash
# 依存は作業用フォルダに入れる（リポジトリの package.json には入れない）
npm i --prefix <作業用フォルダ> playwright-core@1.55.0
NODE_PATH=<作業用フォルダ>/node_modules node .claude/skills/eyecatch-image/scripts/render_eyecatch.mjs articles/book-review/images/<slug>/eyecatch.json
```
→ `images/<slug>/eyecatch.png`（1600×900）ができる。フォント（`assets/fonts/`）はスクリプトが読み込む。

### 6. 見て直す
書き出した PNG を Read で開いて確かめる。
- 書名が1行（または指定どおり2行）に収まり、マーカーと重なって読めるか
- 背景のモチーフがパネル・表紙に隠れていないか
- 色がうるさすぎないか（モチーフの色はパレット＋淡色まで）

### 7. 記事につなぐ
記事の front matter に追加する（Sanity へのアップロードでアイキャッチになる）：
```yaml
heroImage: "images/<slug>/eyecatch.png"
heroImageAlt: "『書名』（著者名）の書評アイキャッチ"
```

### 8. 報告
- 画像のパス、選んだモチーフ
- 表紙が仮の本のときは「`images/<slug>/cover.jpg` に表紙のスクリーンショットを置いて、もう一度『アイキャッチを作って』と伝えてください」と書く
