# 矢野英人のケア・ナレッジ帳

書評記事の「感想」や、介護記事を書くときに AI が読む、筆者自身の経験と考え方の置き場です。
書評スキル（`.claude/skills/book-review-article/`）はこのファイルを読んでから感想を書きます。

## このファイルのルール

- **個人が特定されない形で書く**：名前・施設名・地域・日付・珍しい病名の組み合わせは書かない（守秘義務・個人情報保護）
- **ここにないエピソードを AI が作らない**：感想で具体例を使うときは、このファイルにあるものだけ。なければ「〜ことがあります」と一般的に書く
- **出典を残す**：各項目の末尾に、どこから拾ったかを書く（`出典：〇〇`）。本人の聞き取りは `出典：本人（YYYY-MM）`
- **公開してよい内容だけ**：このファイルは GitHub のリポジトリに保存されます
- 【要確認】が付いた項目は、過去の文章から AI が読み取ったもの。本人が確認したら【要確認】を消す

## 2. 現場エピソード

### E-001 家具の配置換えで、歩行器での移動がスムーズに

- **状況**：80歳代の女性、要介護1。一人暮らしで、週2回デイケアに通っていた。筆者がリハビリで担当
- **出来事**：介護保険外の家事代行サービス（スタッフ1名・1時間・5,000円）で、タンスや作業デスクなど重い家具を移動した
- **結果**：家具の配置が変わり、歩行器を使った室内の移動がスムーズになった。生活動線が改善した
- **筆者の視点**：高齢者にとって家具の配置は転倒リスクに関わる。単なる「模様替え」は介護保険では対応できないが、保険外サービスに利用登録しておけば、急な困りごとにもすぐ頼める
- **テーマ**：住環境、転倒予防、自立支援、一人暮らし、介護保険外サービス
- 出典：過去記事「介護保険外サービスとは？種類と費用相場」3章
