# はじめにお読みください

このフォルダは、無料講座「AIに仕事を任せる3日間」（2026年9月28〜30日）の配布物です。

**3行のメモを、X投稿1本とメルマガ1通の下書きに変えてくれる「手順書」**が入っています。

入っているもの：

- `SKILL.md` … AIに渡す手順書（本体）
- `settings.md` … あなたのことを3つ書いておくファイル（空欄のままでOK）
- `README.md` … これ

---

## 置き方（どのツールでも共通）

### いちばん簡単な方法

**Day1で作った `AI-office` フォルダに、このフォルダごと入れてください。**

```
デスクトップ
└ AI-office
  └ memo-to-post      ← このフォルダを、ここに入れる
    ├ SKILL.md
    ├ settings.md
    └ README.md
```

置いたら、それで終わりです。

---

## 使い方

### ChatGPT デスクトップアプリの場合

1. `AI-office` フォルダを開いた状態にする
2. 次のように頼む

```
memo-to-post フォルダの SKILL.md を読んで、
その手順どおりに、このメモを投稿文にしてください。

（ここに3行のメモを貼る）
```

### Claude デスクトップアプリの場合

同じです。`AI-office` フォルダを見せた状態で、上と同じように頼んでください。

### Claude Code を使っている場合

`SKILL.md` を `~/.claude/skills/memo-to-post/` に置くと、
`「メモを投稿にして」` と言うだけで呼び出せます。

置き方が分からなければ、Claude Code にこう言ってください：

```
このフォルダの SKILL.md を ~/.claude/skills/memo-to-post/ に置いて
```

## ⚠️ ブラウザ版（web版）をお使いの方へ

**ブラウザで使うChatGPT・Claudeは、あなたのパソコンのファイルを書き換えられません。**

そのため `settings.md` への保存ができず、**毎回3つの質問をされます。**
答えれば、その会話の中ではちゃんと動きます。

保存まで含めて使いたい場合は、**デスクトップアプリ**（PCに入れるほう）をお使いください。
Day1で準備したものです。

## 最初の1回

初めて使うとき、AIが3つ質問してきます。

1. あなたのことを一言で
2. 一人称（わたし／私／僕 など）
3. 文体（です・ます調／だ・である調）

答えると `settings.md` に保存されて、**次からは聞かれません。**

## うまくいかないとき

| こうなったら | こう言ってください |
|---|---|
| 手順書を読みに行ってくれない | 「memo-to-post フォルダの中の SKILL.md を読んで」 |
| 出てきた文章が自分っぽくない | 「もっとやわらかく」「もっと短く」と、そのまま言う |
| 設定を変えたい | 「settings.md を開いて、一人称を『僕』に変えて」 |
| 壊してしまった | このフォルダをもう一度ダウンロードして、入れ直す |
| 文章に【要確認】と書いてある | **そこだけ自分で確かめて、消してから**投稿してください（AIが「ここは分からない」と印をつけた場所です） |
| 文章が短い | メモが短ければ、短いままで正解です。無理に長くしません |

## 3日目にやること

**この手順書は、書き換えて使うためのものです。**

`SKILL.md` は、ただの日本語のテキストです。開けば読めます。
3日目に、1か所だけ自分用に書き換えます。

書き換える前に、**必ずコピーを取ってください。**
（ファイルを複製して、控えを `SKILL_original.md` などアルファベットの名前にしておく）

コピーがあれば、壊しても戻れます。
